# 0.1.0.82

This Jellyfin `10.11.11` private-testing release contains only
`Jellyfin.Plugin.CollectionManager.dll` and the license—never Jellyfin
configuration, collection backups, logs, cached data, NFO files, or media.

It adds an adjustable **Text line spacing** percentage directly below **Text
size** in Text Focused Collection Art. The setting updates the preview
immediately, is saved with the other Text Focused preferences, and is used when
applying collection or library artwork. Existing preferences retain the prior
112% spacing by default.

Use the repository's `manifest.json` URL in **Dashboard → Plugins →
Repositories** to install or update the plugin.
