MEDIA COLLECTION MANAGER — PRODUCT GOALS
=========================================

Purpose
-------
Media Collection Manager is a Jellyfin 10.11.11 dashboard plugin for turning
existing local library metadata into normal Jellyfin collections. It never
fetches, adds, changes, or removes media metadata or NFO files.

Current dashboard plan
----------------------

1. Main Settings
   - Select and save one or more Jellyfin libraries.
   - Save the newly-added-media preference.
   - Scan saved libraries into a local, read-only metadata catalog.
   - Show an expandable, paginated per-library metadata overview.

2. Individual Tag Collections
   - Create one draft per selected metadata value.
   - Let each draft include matching media from selected additional libraries.
   - Preview, title, skip, and create each native Jellyfin collection safely.

3. Combined Tag Collections
   - Create one draft from two or more selected metadata values.
   - Include the unique union of media matching any selected value.
   - Support selected additional libraries, previews, title conflicts, and
     native collection creation.

4. Multi-Match Tag Collections
   - Create one draft from two or more selected metadata values.
   - Include only media matching every selected value.
   - Support selected additional libraries, previews, title conflicts, and
     native collection creation.

Future tabs will be planned separately before implementation.

Safety boundaries
-----------------
- Use normal Jellyfin collections and retain native Jellyfin collection controls.
- Read all available existing Jellyfin and local-NFO metadata, including values
  created by Media Tagging Manager, without limiting the catalog to that plugin.
- Keep Provider and Network distinct metadata types where the source metadata
  identifies them as such.
- Never create duplicate collections silently; require an administrator choice.
