MEDIA COLLECTION MANAGER — PRIVATE TESTING AND RESULTS TRACKER
===============================================================

Purpose
-------
This document records every private verification activity for Media Collection
Manager. It is deliberately separate from project-goals.txt: goals describe
what the product must do; this file records what was actually exercised, the
environment used, the observed result, and any follow-up work.

Result key
----------
[ ] Not run
[~] In progress or needs follow-up
[x] Passed
[!] Failed
[?] Blocked or environment-dependent

Testing rules
-------------
- Record the Jellyfin version, plugin build/version, operating system, and
  relevant library/NFO setup for each result.
- Describe observed behavior, not expected behavior alone.
- Preserve sample item names, source values, and error messages when useful.
- Do not place credentials, API keys, server URLs, or private media paths here.
- A failed or incomplete check should state the next action needed.
