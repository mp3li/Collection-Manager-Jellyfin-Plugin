Multi-Collection/Library Gradient Art Settings

This tab is a tool to create specific gradient art sets for collections or libraries, usually for displaying on the Home Screen in a custom section. The dev that created this plugin is currently working on a Home Screen Sections plugin that will work hand in hand with this tool. This tool will replace the backgrounds in all selected collections/libraries with a combined smooth gradient of your chosen colors, meant to be arranged in a row side by side. You must either select all collections, or all libraries, not a mixture.

Select Gradient

Select up to three gradient colors for your gradient art.

Select Collections for Multi-Collection Gradient Art

Select collections here to be able to create a multi-collection gradient art set for. The current art for the selected collections must have been created/applied by this plugin for this tool to work.

Select Libraries for Multi-Collection Gradient Art

Select libraries here to be able to create a multi-collection gradient art set for.
