Media Collection Manager

Build normal Jellyfin collections from the metadata already in your server. Collections created here remain ordinary collections: use their three-dot menus for images, metadata, sharing, deletion, and every other native Jellyfin collection action.

Metadata sources and library scope

Media Collection Manager only reads metadata that already exists. Choose whether it reads Jellyfin's library metadata, matching local NFO sidecars, or both. Nothing here changes your media files, NFOs, tags, or Jellyfin metadata.

This scope applies to discovered values, automatic rules, and the manual-media search area.

Automatic collections

A rule creates one collection from one or more selected values. Provider and Network rules read existing local provider/network metadata and tags, including values written by your downloader and metadata tools.

Saved rules

Run a rule immediately, edit its definition, or stop managing it without deleting its Jellyfin collection.

Bulk create by metadata

Select several values to create one standard collection for each of them. This is useful for making a whole provider, network, genre, cast, studio, director, composer, or year shelf at once.

Manual collection and bulk membership

Search your media, select as many results as you need, then create a collection in one action. For existing collections, use their normal Jellyfin three-dot menu; this plugin never replaces those controls.

Watching and scheduled reconciliation

When enabled, changed tags, genres, people, studios, years, and NFO-backed metadata trigger a quiet-period reconciliation. Changes made by Media Tagging Manager are handled through this same path.

The dashboard task checks hourly but respects this minimum. You can also run it immediately from Scheduled Tasks or with the button above.
