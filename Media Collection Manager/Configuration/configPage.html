Media Collection Manager

Main Settings

Media Collection Manager reads the metadata already assigned to your media and builds a local catalog you can later use to create and maintain Jellyfin collections.

Metadata tags are descriptive information connected to a media item, such as genres, providers, networks, studios, directors, cast members, composers, years, custom tags, and other metadata already available in your Jellyfin libraries or local NFO files. For example, a title may have tags such as Provider: MarqueeTV, Network: HBO, Opera, Broadway, or Live Performance.

This plugin uses all available metadata tags; it does not fetch, add, edit, or remove metadata from your media. It was especially designed to work alongside the Media Tagging Manager Jellyfin Plugin, which can create and assign many of the tags that Media Collection Manager can then use to organize your library into collections.
